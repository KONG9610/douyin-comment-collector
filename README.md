# 抖音评论采集助手

一款面向 Windows 的本地抖音视频与评论采集工具。支持作品链接批量导入、作者主页作品选择、视频下载、评论与回复采集，以及 Excel、CSV、JSON 导出。

本说明对应 **2026 年 9 月 9 日的 0.3.0 版本**，不包含后续新增的论文研究专用导出和音频转录功能。

> 仅限学术研究、教学交流、个人学习等非商业目的。首次使用采集功能前，需要阅读并同意软件内的《使用须知与免责声明》。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 作品链接导入 | 支持单条或多条作品链接、分享文案，识别重复链接并提示无效内容 |
| 作者主页采集 | 读取作者作品列表，按日期或数量筛选，勾选后加入队列 |
| 视频下载 | 保存当前能够获取的视频文件 |
| 评论与回复 | 采集一级评论及可获取的回复，保留文字表情、换行和评论关联关系 |
| 评论数量设置 | 展示可取得的平台评论总数；默认每个作品采集 100 条，支持逐项修改 |
| 评论图片 | 图片评论标记、预览及可选下载 |
| 批量任务 | 串行队列、进度查看、暂停、结束保存、续采及分项重试 |
| 评论筛选 | 按关键词、时间、点赞数、IP 属地和评论层级筛选，支持时间与点赞排序 |
| 数据导出 | 导出 Excel、CSV、JSON，并保留用于恢复任务的 JSONL 文件 |
| 本地管理 | 自定义保存目录、登录状态检测、磁盘空间检查、临时文件清理和诊断导出 |

**评论上限按每个作品分别计算，一级评论和回复共用该作品的上限。** 页面筛选只改变查看结果，不修改已经保存的数据；导出包含全部已采集结果，不是仅导出当前筛选结果。

## 运行环境

- Windows 10 / 11，64 位（x64）。
- 已安装 Microsoft Edge。
- 可正常访问抖音的网络环境。
- 足够的本地存储空间；下载视频和评论图片会增加空间占用。

使用安装包时，无需另外安装 Node.js、Python 或开发工具。

## 快速开始

1. 如果仓库 Releases 页面已经发布安装包，下载并安装 `DouyinCommentCollector-0.3.0-Setup.exe`。
2. 启动软件，点击“打开抖音 / 登录”，在软件打开的独立 Edge 窗口中使用自己的账号登录。
3. 阅读并同意软件内的使用声明。
4. 在“作品链接”中粘贴链接或分享文案，识别并勾选作品；也可以切换到“作者主页”，读取并选择作品。
5. 选择是否下载视频、采集评论、包含回复、下载评论图片，并设置每个作品的评论上限。
6. 加入队列，在“任务中心”查看进度。
7. 采集结束后，在“作品与评论”中查看结果、筛选评论或打开导出文件。

遇到登录失效或平台验证时，请在 Edge 窗口中手动处理，再回到软件继续。工具不自动破解验证码，也不保证能够访问受限内容。

## 保存位置与文件

0.3.0 安装版默认将采集结果保存到当前用户“下载”目录下的“抖音评论采集助手”文件夹，可在设置中更改。设置新的保存位置只影响新任务，续采仍写入原任务目录。

登录状态、设置和任务记录默认保存在当前用户的 `AppData/Roaming/DouyinCommentCollector` 目录。源码运行版使用项目本地目录，具体以软件设置显示的路径为准。

作品通常按作者和作品信息分目录归档：

| 文件 | 内容 |
| --- | --- |
| `video.mp4` | 下载完成的视频 |
| `video.json` | 作品 ID、标题、作者、原链接及采集信息 |
| `comments.jsonl` | 逐页追加的规范化评论记录，用于恢复和去重；不是完整接口原始响应 |
| `comments.json` | 全部已采集评论，包含评论 ID、正文、层级、回复关联、时间及可取得的图片地址等 |
| `comments.csv` | 便于表格软件读取的 UTF-8 BOM 文件，时间使用 UTC |
| `comments.xlsx` | 中文表头的 Excel 文件，时间显示为北京时间，长 ID 按文本保存 |
| `images/` | 可选下载的评论图片及映射信息 |
| `task.json` | 任务配置、状态、停止原因与恢复信息 |

## 暂停与断点续采

- “暂停”用于暂停当前评论采集；已经开始传输的视频可能继续完成。
- “暂停后续任务”用于停止启动下一项任务。
- “结束并保存”会保存当前已取得的结果；队列中的后续任务可能继续执行。
- “继续原任务”或“续采评论”复用原任务目录，并按评论 ID 去重。
- 恢复时会重新打开作品并翻页，不保证平台再次返回此前遗漏的内容。
- 重新打开软件后，队列默认不会自动开始运行。

## 实现方式

桌面界面基于 Electron，使用 Playwright 驱动专用 Edge 浏览器，通过正常页面访问、滚动和展开回复等操作，读取页面加载过程中返回的作品与评论数据，并保存到本地。

采集效果依赖账号访问权限、登录状态、平台页面结构及接口返回情况。本项目不是抖音官方产品，也不提供平台访问权限或数据完整性保证。

## 从源码运行

以下命令适用于已经检出 0.3.0 对应源码的项目目录。请先安装 Node.js 和 npm：

```bash
npm install
npm start
```

在 Windows 上构建安装包：

```bash
npm run dist
```

构建产物默认位于 `dist/`。开发依赖的首次安装可能需要下载 Electron 等组件。

## 已知限制

- **平台显示评论数不等于一定能够采集到的数量。** 删除、折叠、访问限制、暂未返回的数据，以及一级评论与回复的统计口径差异，都可能影响结果。
- 达到设定上限、任务结束或导出成功，都不代表已取得全部评论。
- 点赞数、评论总数等表示采集时能够取得的当前值，不能当作作品发布时的历史数量。
- 不保证视频为原片或最高画质；本版本不支持图文作品的媒体下载。
- 作者主页列表可能只能取得部分作品，不能据此认定该账号没有更早作品。
- 评论图片原链接可能失效，建议按需下载留存。
- 平台页面或接口变化可能导致部分功能失效，需要后续维护。
- 本版本不包含关键词搜索、音频转文字、情绪分析、跨平台采集、云端同步和定时增量监控。
